## How the process works

The full setup follows four main stages. Each stage must be completed in order.

<Steps>
  <Step title="Reinstall Windows">
    You start with a clean Windows installation. This removes traces left by previous anti-cheat software and ensures no residual ban data is present on your system.
  </Step>
  <Step title="Configure your BIOS">
    You update your BIOS firmware, then enable TPM, Virtualization, and Secure Boot. Mosab Store requires these features to be active to function correctly.
  </Step>
  <Step title="Set up Windows">
    After reinstalling, you configure Windows — disabling Defender, installing required Visual C\+\+ runtimes and drivers, and adjusting network settings.
  </Step>
  <Step title="Run the spoofer">
    You download the Mosab Store loader, enter your license key to authenticate, and run the spoof. The loader walks you through each action and confirms when the process is complete.
  </Step>
</Steps>

## License key and loader

Mosab Store uses a license key-based loader system. After purchase, you receive a key that authenticates your copy of the software. You enter this key in the loader before running the spoof. Keep your key secure — do not share it.

## Support

If you run into any issues, open a ticket in the Mosab Store Discord server. Support is provided through tickets only. Do not skip steps and then contact support expecting a fix — work through the documentation in order first.
