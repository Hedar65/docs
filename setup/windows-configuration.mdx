After reinstalling Windows, you need to configure the system before running Spoofer. Work through each section below in order. Do not restart your computer until you have completed all steps — the final step will prompt you to restart.

---

## 2. Disable Startup Programs and Background Apps

Reduce unnecessary background activity that could interfere with the spoofer.

<Steps>
  <Step title="Disable background apps">
    Go to **Settings → Privacy → Background apps** and turn off background app activity.
  </Step>
  <Step title="Disable startup programs">
    Open **Task Manager** (Ctrl \+ Shift \+ Esc), click the **Startup** tab, and disable every entry in the list.

    <img
      src="/images/select-an-app-that-has-the-enabled-status-then-click-the-disable-button-towards-the-upper-right-corner-of-the-window.avif"
      alt="Select An App That Has The Enabled Status Then Click The Disable Button Towards The Upper Right Corner Of The Window"
      title="Select An App That Has The Enabled Status Then Click The Disable Button Towards The Upper Right Corner Of The Window"
      style={{ width:"98%" }}
    />
  </Step>
</Steps>

<Warning>
  Do **not** restart your computer after this step. Continue through all remaining steps first and restart only at the end.
</Warning>

## 3. Configure Network Adapter

Strip unnecessary protocols from your network connection to reduce potential identifier exposure.

<Steps>
  <Step title="Open Network Connections">
    Press **Win \+ R**, type `ncpa.cpl`, and press **Enter**.
  </Step>
  <Step title="Open adapter properties">
    Right-click your active internet connection (Ethernet or Wi-Fi) and select **Properties**.
  </Step>
  <Step title="Uncheck all items except two">
    In the properties list, uncheck everything **except** the following two items:

    - **QoS Packet Scheduler**
    - **Internet Protocol Version 4 (TCP/IPv4)**
  </Step>
  <Step title="Save changes">
    Click **OK** to apply.
  </Step>
</Steps>

## 6. Disable UAC (User Account Control)

User Account Control (UAC) prompts can interfere with the spoofer's ability to make system-level changes. Disable it before running the loader.

<Steps>
  <Step title="Open UAC settings">
    Open the **Start** menu and search for **UAC**. Select **Change User Account Control settings**.
  </Step>
  <Step title="Set to Never notify">
    Drag the slider all the way down to **Never notify**.
  </Step>
  <Step title="Confirm the change">
    Click **OK** and accept any confirmation prompt that appears.

    <img
      src="/images/image.png"
      alt="Capture 2026 05 26 0506"
      title="Capture 2026 05 26 0506"
      style={{ width:"88%" }}
    />
  </Step>
</Steps>

<Warning>
  Disabling UAC reduces your system's protection level. Only install software you trust while UAC is turned off.
</Warning>

## 7. Install the Latest Graphics Drivers

Install the latest drivers for your GPU from your manufacturer's official website. Outdated or missing drivers can cause issues after Windows reinstallation.

<Tabs>
  <Tab title="NVIDIA">

  </Tab>
  <Tab title="AMD">

  </Tab>
  <Tab title="Intel">

## 8. Enable Core Isolation / Memory Integrity

Memory Integrity is a Windows security feature that Mosab Spoofer requires to be active. Enable it in Windows Security before running the loader.

<Steps>
  <Step title="Open Windows Security">
    Open the **Start** menu, search for **Windows Security**, and open the app.

    <img
      src="/images/ح-Windows-Security.png"
      alt="ح Windows Security"
      title="ح Windows Security"
      style={{ width:"89%" }}
    />
  </Step>
  <Step title="Go to Device Security">
    Click **Device Security** in the left panel.
  </Step>
  <Step title="Open Core Isolation Details">
    Under the **Core isolation** section, click **Core isolation details**.
  </Step>
  <Step title="Enable Memory Integrity">
    Toggle **Memory Integrity** to **On**.

    <Frame>
      <img
        src="/images/Toggle-Memory-Integrity-to-On.png"
        alt="Toggle Memory Integrity To On"
        title="Toggle Memory Integrity To On"
      />
    </Frame>
  </Step>
</Steps>

<Note>
  If prompted to restart after enabling Memory Integrity, you can restart now — this counts as the final restart at the end of this guide.
</Note>
