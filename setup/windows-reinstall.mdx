Before using Redline Spoofer, you must perform a clean reinstallation of Windows. This ensures all hardware identifiers are properly reset and that no leftover ban traces remain on your system. There are two reinstallation methods — Normal and RAID — and the right choice depends on your game and ban history.

## Which reinstall method should you use?

| Game | Recommendation |
|---|---|
| **Fortnite** | Use Normal reinstall. If you have been banned more than 3 times on the same hardware, use RAID reinstall. |
| **Rust / Apex / EAC/BE games** | Use Normal reinstall. |
| **Valorant** | Use Normal reinstall. If you have been banned more than twice on the same hardware, use RAID reinstall. |

## Normal Reinstall (USB — Recommended)

Reinstalling Windows via USB is strongly recommended because it lets you wipe every disk completely before installation.

**Difficulty:** 8/10 (Very Easy) &nbsp;&nbsp; **Time:** ~15 minutes

<Note>
  If multiple attempts have failed and you keep getting banned on the same machine, the problem may be tied to the disk itself. In that case, the USB reinstall method below is the right approach.
</Note>

<Note>
  After reinstalling, Windows will usually install network drivers automatically. If it does not, download your motherboard's LAN driver beforehand and save it to the USB so you have it available.
</Note>

<Steps>
  <Step title="Download the Windows 10 Media Creation Tool">
    Go to [microsoft.com](https://www.microsoft.com/en-us/software-download/windows10) and click **Download Now** to get the Media Creation Tool.
  </Step>

  <Step title="Run as administrator">
    Right-click the downloaded tool and select **Run as administrator**.
  </Step>

  <Step title="Create installation media">
    When prompted, select **Create installation media (USB flash drive, DVD, or ISO file)**, then choose **USB Flash Drive** as the media type.

    Use all recommended default options and wait for the process to complete. Your USB drive should end up with a Windows setup structure on it.
  </Step>

  <Step title="Boot from the USB">
    Hold **SHIFT**, then click **Restart** (keep holding SHIFT until the recovery screen appears).

    On the blue screen, choose **Use a device**, then select your USB drive (also shown as "Flash Drive").
  </Step>

  <Step title="Select Windows 10 Pro">
    When the Windows Setup wizard asks which version to install, select **Windows 10 Pro**.

    <Warning>
      You must select **Windows 10 Pro** specifically. Do not choose Home or any other edition.
    </Warning>
  </Step>

  <Step title="Skip the product key">
    When asked for a product key, click **I don't have a product key**. You do not need one to proceed.
  </Step>

  <Step title="Clean every disk using diskpart">
    On the installation screen where you choose a disk, press **SHIFT + F10** to open a Command Prompt window.

    Run the following commands in order:

    ```cmd
    diskpart
    ```

    ```cmd
    list disk
    ```

    This shows all disks on your system. For **each disk except the USB**, run:

    ```cmd
    select disk X
    ```

    ```cmd
    clean
    ```

    Replace `X` with the disk number shown in the list. Repeat `select disk X` + `clean` for every internal disk.

    After running `clean`, you should see a message like: `DiskPart succeeded in cleaning the disk.`

    Close the CMD window and click **Refresh** in the installer.

    <Warning>
      **Do NOT run `clean` on your USB drive.** USB drives typically appear last in the list and have a much smaller size than your internal drives (HDD/SSD). If you are unsure which disk is the USB, check the size column — the USB will be significantly smaller.
    </Warning>

    <Tip>
      If you have one internal disk, run `select disk 1` then `clean`. If you have two, also run `select disk 2` then `clean`. Repeat as needed for each internal disk.
    </Tip>
  </Step>

  <Step title="Select the main disk and continue">
    After refreshing, select your main disk shown as **Unallocated Space**, then click **Next**. The installation will begin.
  </Step>

  <Step title="Create a local offline account">
    During Windows setup, when asked to sign in with a Microsoft account, choose to create a **Local (Offline) Account** instead.

    <Warning>
      Do **not** sign in to your old Microsoft account. Create a new local account or a brand-new Microsoft account. Using your previous account can re-link identifiers tied to the ban.
    </Warning>
  </Step>

  <Step title="Disable all privacy settings">
    When Windows asks about privacy settings and diagnostics options, turn **everything off**.
  </Step>

  <Step title="Post-install account hygiene">
    After setup completes, follow these rules:

    - Do **not** sign in to OneDrive with your old account.
    - Do **not** sign in to GeForce Experience with your old account.
    - Do **not** sign in to Medal with your old account.
  </Step>

  <Step title="Install Visual C++ Redistributable">
    Download and install the Visual C++ runtime to prevent errors when running the spoofer:

    [https://aka.ms/vs/17/release/vc_redist.x64.exe](https://aka.ms/vs/17/release/vc_redist.x64.exe)
  </Step>
</Steps>

## Alternative: Reinstall Without a USB

If you do not have a USB drive available, you can reset Windows directly from within the OS. This method takes significantly longer (1–3 hours) and is less thorough than the USB method.

Navigate to:

```
Settings > Update & Security > Recovery > Reset this PC > Remove everything
```

When prompted, configure the following options:

- **Cloud download** — Yes
- **Change settings → Clean data** — Yes
- **Delete files from all drives** — Yes
- **Download Windows** — Yes

Click **Confirm** and **Next** to begin. Leave the machine until the process finishes.

<Note>
  This method does not give you the same level of disk cleaning as the USB method with `diskpart`. It is acceptable for a first attempt but the USB method is always preferred.
</Note>
