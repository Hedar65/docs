---
title: "How to Update Your BIOS Before Using Redline Spoofer"
description: "Valorant's Vanguard anti-cheat requires an up-to-date BIOS. Update your firmware before reinstalling Windows and running Redline Spoofer."
---

Valorant's anti-cheat system, Vanguard, enforces a minimum BIOS version requirement. If your BIOS is outdated, Vanguard will block the game from launching even after spoofing. You must update your BIOS **before** reinstalling Windows — doing it afterward can cause issues.

<Warning>
  You must complete the BIOS update **before** reinstalling Windows. Do not skip this step or reverse the order.
</Warning>

<Warning>
  Uninstall Vanguard before starting the BIOS update process. You can do this through the Riot support page or by removing it from Add/Remove Programs.
</Warning>

## Verify the BIOS Update Succeeded

After completing the update, confirm that it applied correctly before moving on.

<Steps>
  <Step title="Open System Information">
    Press **Win + R**, type `msinfo32`, and press **Enter**.
  </Step>

  <Step title="Check the BIOS version and date">
    Look for the **BIOS Version/Date** field in the System Summary. If the update succeeded, the version number and date will reflect the new firmware you installed.

    <Note>
      If the version and date have not changed, the update did not apply. Retry the update process using your motherboard manufacturer's guide above.
    </Note>
  </Step>
</Steps>
