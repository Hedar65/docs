Before running Redline Spoofer, you need to enable three specific settings inside your BIOS: TPM (Trusted Platform Module), Virtualization, and Secure Boot. These are required for the spoofer and for games like Valorant to function correctly. Each section below includes video guides for major motherboard brands.

---

## 3. Enable Secure Boot and Reset Keys

Secure Boot must be enabled with freshly loaded keys. The process involves entering the BIOS a second time to delete all existing Secure Boot keys and then reload them.

<Note>
  On some BIOS versions, deleting the keys is sufficient — the system will reload defaults automatically. If your BIOS does not show a separate "Reload" or "Restore" option, just deleting the keys is enough.
</Note>

<Steps>
  <Step title="Enter BIOS and locate Secure Boot settings">
    Restart your machine and press the appropriate key to enter BIOS (usually **Del**, **F2**, or **F10** depending on your board).
  </Step>

  <Step title="Delete all Secure Boot keys">
    Navigate to the Secure Boot section and delete all existing keys.
  </Step>

  <Step title="Reload default keys">
    After deleting, select the option to reload or restore default keys. Save and exit BIOS.
  </Step>
</Steps>

Follow the guide for your motherboard brand:

## Verify All Settings Inside Windows

After completing all three BIOS changes, boot into Windows and confirm each setting is active.

### Secure Boot

<Steps>
  <Step title="Open System Information">
    Press **Win + R**, type `msinfo32`, and press **Enter**.
  </Step>

  <Step title="Check Secure Boot State">
    In the System Summary panel, find **Secure Boot State**. It must show **On**.
  </Step>
</Steps>

### TPM

<Steps>
  <Step title="Open TPM Management">
    Press **Win + R**, type `tpm.msc`, and press **Enter**.
  </Step>

  <Step title="Confirm TPM status">
    The status section should display: **The TPM is ready for use.**
  </Step>
</Steps>

### Virtualization

<Steps>
  <Step title="Open Task Manager">
    Press **Ctrl + Shift + Esc** to open Task Manager.
  </Step>

  <Step title="Navigate to Performance → CPU">
    Click the **Performance** tab, then select **CPU** from the left panel.
  </Step>

  <Step title="Confirm Virtualization is Enabled">
    Look for the **Virtualization** field in the bottom-right section. It must show **Enabled**.
  </Step>
</Steps>
