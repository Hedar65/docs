## التثبيت العادي (USB — موصى به)

إعادة تثبيت Windows عبر USB موصى بها بشدة لأنها تتيح لك مسح كل قرص بالكامل قبل التثبيت.

**الصعوبة:** 8/10 (سهل جداً)    **الوقت:** ~15 دقيقة

<Note>
  إذا فشلت محاولات عديدة واستمر الحظر على نفس الجهاز، فقد تكون المشكلة مرتبطة بالقرص نفسه. في هذه الحالة، طريقة إعادة التثبيت عبر USB أدناه هي النهج الصحيح.
</Note>

<Note>
  بعد إعادة التثبيت، عادةً ما يقوم Windows بتثبيت تعريفات الشبكة تلقائياً. إذا لم يفعل، نزّل تعريف LAN للوحة الأم مسبقاً واحفظه على USB.
</Note>

<Steps>
  <Step title="تنزيل Rufus لإنشاء USB">
    نزّل Rufus من [rufus.ie](https://rufus.ie/) — سيكتب ملف ISO على فلاش USB.

    ![Rufus](/images/rufus.png)
  </Step>
  <Step title="تشغيل Rufus كمسؤول">
    اضغط بزر الفأرة الأيمن على Rufus واختر **Run as administrator**.
  </Step>
  <Step title="حرق النسخة على الفلاشة">
    في Rufus:

    1. اختر فلاش USB من **Device**.
    2. اضغط **SELECT** واختر ملف ISO الخاص بـ  WIN 10 PRO .
    3. اترك **Partition scheme** على **GPT** و **Target system** على **UEFI**.
    4. اضغط **START**.

    عندما تظهر نافذة تخصيص Windows 10  ، يمكنك اختياراً تفعيل **Remove requirement for an online Microsoft account** و **Disable data collection**.

    انتظر حتى يظهر Rufus **READY** باللون الأخضر.

    <img
      src="/images/rufus-1.png"
      alt="RUISO2"
      title="RUISO2"
      style={{ width:"57%" }}
    />
  </Step>
  <Step title="الإقلاع من USB">
    اضغط مع الاستمرار على **SHIFT**، ثم اضغط **Restart** (استمر بالضغط حتى تظهر شاشة الاسترداد).

    في الشاشة الزرقاء، اختر **Use a device**، ثم اختر USB.

    <img
      src="/images/1234-1.png"
      alt="1234 1"
      title="1234 1"
      style={{ width:"94%" }}
    />
  </Step>
  <Step title="اختيار Windows 10 pro Super Lite + Defender">
    عندما يسألك معالج إعداد Windows عن أي نسخة تثبت، اختر **Windows 11 Pro**.

    <img
      src="/images/1-2-se.png"
      alt="Cant Select Windows 11 Edition During Clean Installation Thumbnail 1"
      title="Cant Select Windows 11 Edition During Clean Installation Thumbnail 1"
      style={{ width:"95%" }}
    />

    <Warning>
      يجب اختيار **Windows** 10 pro Super Lite \+ Defender
    </Warning>
  </Step>
  <Step title="تخطي مفتاح المنتج">
    عندما يُطلب مفتاح المنتج، اضغط **I don't have a product key**.

    <img
      src="/images/dad-1.png"
      alt="Dad 1"
      title="Dad 1"
      style={{ width:"96%" }}
    />
  </Step>
  <Step title="مسح كل قرص باستخدام diskpart">
    في شاشة التثبيت حيث تختار القرص، اضغط **SHIFT \+ F10** لفتح نافذة Command Prompt.

    <img
      src="/images/da-1.png"
      alt="Da 1"
      title="Da 1"
      style={{ width:"97%" }}
    />

    شغّل الأوامر التالية بالترتيب:

    ```cmd
    diskpart
    ```

    ```cmd
    list disk
    ```

    هذا يعرض جميع الأقراص. لكل قرص **عدا USB**، شغّل:

    ```cmd
    select disk X
    ```

    ```cmd
    clean
    ```

    استبدل `X` برقم القرص الظاهر. كرر `select disk X` \+ `clean` لكل قرص داخلي.

    <Warning>
      **لا تشغّل `clean` على قرص USB.** أقراص USB عادةً تظهر في النهاية وحجمها أصغر بكثير من الأقراص الداخلية.
    </Warning>

    <Tip>
      إذا كان لديك قرص داخلي واحد، شغّل `select disk 1` ثم `clean`. إذا كان لديك قرصان، شغّل أيضاً `select disk 2` ثم `clean`.
    </Tip>
  </Step>
  <Step title="اختر القرص الرئيسي وأكمل">
    بعد التحديث، اختر القرص الرئيسي الظاهر كـ **Unallocated Space**، ثم اضغط **Next**.
  </Step>
  <Step title="إنشاء حساب محلي بدون اتصال">
    أثناء تثبيت نظام التشغيل Windows، عندما يُطلب منك تسجيل الدخول باستخدام حساب Microsoft، اضغط على مفتاحي Shift \+ F10 واكتب START MS-CXH:LOCALONLY

    <img
      src="/images/Start-ms-cxh-1.png"
      alt="Start Ms Cxh 1"
      title="Start Ms Cxh 1"
      style={{ width:"98%" }}
    />

    <Warning>
      لا تسجّل الدخول بحساب Microsoft القديم. أنشئ حساباً محلياً جديداً أو حساب Microsoft جديد تماماً.
    </Warning>
  </Step>
  <Step title="تعطيل جميع إعدادات الخصوصية">
    عندما يسأل Windows عن إعدادات الخصوصية والتشخيص، أوقف **كل شيء**.

    <img
      src="/images/windows-11-fresh-install-settings-1.avif"
      alt="Windows 11 Fresh Install Settings 1"
      title="Windows 11 Fresh Install Settings 1"
      style={{ width:"97%" }}
    />
  </Step>
  <Step title="نظافة الحساب بعد التثبيت">
    بعد اكتمال الإعداد، اتبع هذه القواعد:

    - **لا** تسجّل الدخول إلى OneDrive بحسابك القديم.
    - **لا** تسجّل الدخول إلى GeForce Experience بحسابك القديم.
    - **لا** تسجّل الدخول إلى Medal بحسابك القديم.
  </Step>
  <Step title="تثبيت Visual C++ Redistributable">
    نزّل وثبّت Visual C\+\+ runtime لمنع الأخطاء:

    [https://aka.ms/vs/17/release/vc\_redist.x64.exe](https://aka.ms/vs/17/release/vc_redist.x64.exe)
  </Step>
</Steps>
