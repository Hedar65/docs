## 3. تفعيل Secure Boot وإعادة تعيين المفاتيح

<Note>
  في بعض إصدارات BIOS، حذف المفاتيح كافٍ — سيعيد النظام تحميل الافتراضيات تلقائياً.
</Note>

<Steps>
  <Step title="ادخل BIOS وحدّد إعدادات Secure Boot">
    أعد تشغيل جهازك واضغط المفتاح المناسب لدخول BIOS (عادةً **Del** أو **F2** أو **F10**).
  </Step>
  <Step title="حذف جميع مفاتيح Secure Boot">
    انتقل إلى قسم Secure Boot واحذف جميع المفاتيح الموجودة.
  </Step>
  <Step title="إعادة تحميل المفاتيح الافتراضية">
    بعد الحذف، اختر خيار إعادة تحميل أو استعادة المفاتيح الافتراضية. احفظ واخرج.
  </Step>
</Steps>

## التحقق من الإعدادات داخل Windows

### Secure Boot

<Steps>
  <Step title="فتح System Information">
    اضغط **Win \+ R**، اكتب `msinfo32`، واضغط **Enter**.

    <Frame>
      <img
        src="/images/msinfo-1.png"
        alt="Msinfo 1"
        className="rounded-xl"
        title="Msinfo 1"
        style={{ width:"99%" }}
      />
    </Frame>
  </Step>
  <Step title="تحقق من Secure Boot State">
    في System Summary، ابحث عن **Secure Boot State**. يجب أن تظهر **On**.

    <Frame>
      <img
        src="/images/secure-boot-1.png"
        alt="Secure Boot 1"
        className="rounded-xl"
        title="Secure Boot 1"
        style={{ width:"94%" }}
      />
    </Frame>
  </Step>
</Steps>

### TPM

<Steps>
  <Step title="فتح TPM Management">
    اضغط **Win \+ R**، اكتب `tpm.msc`، واضغط **Enter**.

    <Frame>
      <img
        src="/images/tpm.msc-1.png"
        alt="Tpm Msc 1"
        className="rounded-xl"
        title="Tpm Msc 1"
        style={{ width:"98%" }}
      />
    </Frame>
  </Step>
  <Step title="تأكيد حالة TPM">
    يجب أن تعرض حالة الحالة: **The TPM is ready for use.**

    <Frame>
      <img
        src="/images/trusted-platform-module-management-on-local-computer-windows-10-1.png"
        alt="Trusted Platform Module Management On Local Computer Windows 10 1"
        title="Trusted Platform Module Management On Local Computer Windows 10 1"
        style={{ width:"92%" }}
      />
    </Frame>
  </Step>
</Steps>

### Virtualization

<Steps>
  <Step title="فتح Task Manager">
    اضغط **Ctrl \+ Shift \+ Esc**.
  </Step>
  <Step title="انتقل إلى Performance → CPU">
    اضغط على علامة **Performance**، ثم اختر **CPU**.
  </Step>
  <Step title="تأكيد تفعيل Virtualization">
    ابحث عن حقل **Virtualization** في الأسفل. يجب أن يظهر **Enabled**.

    <Frame>
      ![رهقعشم](/images/رهقعشم.avif)
    </Frame>
  </Step>
</Steps>
