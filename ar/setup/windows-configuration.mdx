---
title: "ضبط Windows بعد إعادة التثبيت لـ Mosab Spoofer"
description: "أكمل إعداد Windows بعد إعادة التثبيت قبل تشغيل Mosab Spoofer."
---

بعد إعادة تثبيت Windows، تحتاج إلى ضبط النظام قبل تشغيل Mosab Spoofer. لا تعد التشغيل حتى تكمل كل الخطوات.

---

## 1. تعطيل Windows Defender / Real-Time Protection

<Tabs>
  <Tab title="يدويًا (Windows Security)">
    <Steps>
      <Step title="فتح Windows Security">
        اضغط مفتاح **Windows** وابحث عن **Windows Security**.

        ![فتح Windows Security](/images/windows-config/defender-01-open-security.png)
      </Step>
      <Step title="تعطيل Real-time protection">
        اذهب إلى **Virus & threat protection → Manage settings**، ثم أوقف **Real-time protection**.

        ![تعطيل real-time protection](/images/windows-config/defender-02-realtime-off.png)
      </Step>
    </Steps>
  </Tab>
  <Tab title="Defender Control Tool">
    <Steps>
      <Step title="تنزيل Defender Control">
        [https://www.sordum.org/files/downloads.php?st-defender-control](https://www.sordum.org/files/downloads.php?st-defender-control)

        ![تنزيل Defender Control](/images/windows-config/dcontrol-01-download.png)
      </Step>
      <Step title="فك الأرشيف">
        كلمة السر:

        ```text
        sordum
        ```

        ![فك الأرشيف](/images/windows-config/dcontrol-02-extract.png)
      </Step>
      <Step title="تشغيل dControl.exe">
        افتح المجلد وشغّل `dControl.exe`.

        ![تشغيل dControl.exe](/images/windows-config/dcontrol-03-run.png)
      </Step>
      <Step title="تعطيل Windows Defender">
        اضغط **Disable Windows Defender**.

        ![تعطيل Defender](/images/windows-config/dcontrol-04-disable.png)
      </Step>
    </Steps>
  </Tab>
</Tabs>

---

## 2. تعطيل برامج بدء التشغيل والتطبيقات الخلفية

<Steps>
  <Step title="تعطيل Background apps">
    اذهب إلى **Settings → Privacy → Background apps**.

    ![تعطيل background apps](/images/windows-config/startup-01-background-apps.png)
  </Step>
  <Step title="تعطيل Startup programs">
    افتح **Task Manager** → **Startup** وعطّل كل إدخال.

    ![تعطيل Startup](/images/windows-config/startup-02-task-manager.png)
  </Step>
</Steps>

<Warning>
  **لا** تعد تشغيل جهازك بعد هذه الخطوة.
</Warning>

---

## 3. ضبط Network Adapter

<Steps>
  <Step title="فتح Network Connections">
    اضغط **Win \+ R**، اكتب `ncpa.cpl`، واضغط **Enter**.

    ![فتح ncpa.cpl](/images/windows-config/network-01-ncpa.png)
  </Step>
  <Step title="فتح Properties المحول">
    اضغط بزر الفأرة الأيمن على الاتصال النشط واختر **Properties**.

    ![Adapter properties](/images/windows-config/network-02-properties.png)
  </Step>
  <Step title="ألغ التحديد عدا اثنين">
    أبق فقط:

    - **QoS Packet Scheduler**
    - **Internet Protocol Version 4 (TCP/IPv4)**

    ![ألغ التحديد](/images/windows-config/network-03-uncheck-items.png)
  </Step>
  <Step title="حفظ التغييرات">
    اضغط **OK**.

    ![حفظ](/images/windows-config/network-04-save.png)
  </Step>
</Steps>

## 5. تثبيت Visual C\+\+ Redistributable (All-in-One)

<Steps>

## 6. تعطيل UAC

<Steps>
  <Step title="فتح إعدادات UAC">
    ابحث عن **UAC** في Start واختر **Change User Account Control settings**.

    ![فتح UAC](/images/windows-config/uac-01-open.png)
  </Step>
  <Step title="اضبط على Never notify">
    اسحب المنزلق للأسفل إلى **Never notify**.

    ![Never notify](/images/windows-config/uac-02-never-notify.png)
  </Step>
  <Step title="تأكيد التغيير">
    اضغط **OK**.

    ![تأكيد](/images/windows-config/uac-03-confirm.png)
  </Step>
</Steps>

## 8. تفعيل Core Isolation / Memory Integrity

<Steps>
  <Step title="فتح Windows Security">
    ابحث عن **Windows Security**.

    ![Windows Security](/images/windows-config/coreiso-01-open-security.png)
  </Step>
  <Step title="اذهب إلى Device Security">
    اضغط **Device Security**.

    ![Device Security](/images/windows-config/coreiso-02-device-security.png)
  </Step>
  <Step title="فتح Core Isolation Details">
    اضغط **Core isolation details**.

    ![Core isolation details](/images/windows-config/coreiso-03-details.png)
  </Step>
  <Step title="تفعيل Memory Integrity">
    فعّل **Memory Integrity**.

    ![Memory Integrity On](/images/windows-config/coreiso-04-memory-integrity.png)
  </Step>
</Steps>
